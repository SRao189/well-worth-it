# Product boundary

This release is an internal Global Career Accelerator assignment demo. It
contains no payments, donations, real personal data, or claim that virtual
droplets represent real-world impact. Public stories and metrics are synthetic
fixtures until a partner supplies a documented license, approval, attribution,
date, and source URL.

The web pilot works without network access. The Expo app and Supabase function
are production-shaped seams; deployment configuration and credentials remain
outside the repository.

The private partner-content repository described in the concept plan is not
created by this release because no rights-cleared partner material is present.
