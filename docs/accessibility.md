# Accessibility notes

- Every core action is a labelled button and supports touch and keyboard paths.
- Assisted hold is represented by a single clear action; success does not depend
  on rapid tapping.
- `prefers-reduced-motion` disables decorative transitions in the web pilot.
- Text uses charcoal on yellow and blue links on warm surfaces; white text is
  never placed on the yellow reward color.
- Native mobile controls inherit screen-reader roles and labels.
