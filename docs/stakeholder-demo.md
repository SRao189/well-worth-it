# Stakeholder demo

1. Start the browser pilot from the repository root: `python -m http.server 4175 -d apps/web`.
2. Open `http://127.0.0.1:4175` and complete both notices in a fresh session.
3. On Main Game, hold the blue control (or use Enter/Space) to clear a phase.
4. Visit Village, Stories, and Leaderboard from the bottom navigation.
5. On Stories, use “Extra credit?” to demonstrate that no donation flow exists.

The browser pilot remains usable without Supabase or council credentials. Every
story and metric shown in this release is synthetic or a placeholder.
